# NovaShop
### Bilingual E-Commerce Platform | PHP & MySQL

NovaShop is a personal Full-Stack Web Development project focused on building a modern bilingual e-commerce platform with a structured backend and an administrative interface.

The platform supports **Persian and German**, combining a modern user interface with PHP-based backend functionality and a MySQL database.

## Project Overview

NovaShop is being developed to demonstrate practical skills in web development, database design, backend programming, and user interface development.

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Implemented Components

- Bilingual structure (Persian and German)
- Product and category management
- Administrative dashboard
- Product management interface
- User management interface
- Database-driven product and category content

## Development Status

**Currently in Development**

NovaShop is an ongoing personal project. Some planned components, including the shopping cart, search functionality, and other e-commerce features, are not yet fully implemented.

New features and improvements are being developed progressively.
